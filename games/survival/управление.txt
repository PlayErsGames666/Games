КЛАВИАТУРА
──────────────────────────────────────────────
  WASD / стрелки ......... ходить по сетке
  Space / E .............. ДЕЙСТВИЕ перед собой:
                           рубить дерево/камень/куст,
                           БИТЬ моба, ломать стену,
                           собрать урожай с грядки
  I ..................... открыть/закрыть РЮКЗАК (инвентарь)
  1 … 9 ................. выбрать ячейку хотбара
  Q ..................... использовать/поставить/скрафтить
                           предмет из выбранной ячейки
  F ...................... быстро съесть ягоду
  P .................... пауза / продолжить
  Esc .................. закрыть рюкзак, иначе — пауза
  Enter ................. заново (после гибели)

  Клавиши читаются по ФИЗИЧЕСКОЙ раскладке — работают
  при русской, украинской и любой другой раскладке.

СЕНСОР / ЭКРАН
──────────────────────────────────────────────
  D-pad (▲◀▶▼) .......... движение
  🤚 .................... собрать
  🍓 / 🔥 / 🕯️ .......... съесть / костёр / факел

РЕСУРСЫ, ХОТБАР И КРАФТ
──────────────────────────────────────────────
  🪵 Ветки — с деревьев   🪨 Камень — с камней
  🍓 Ягоды — с кустов     💎 Руда — иногда с камней
  🍖 Мясо — с убитых мобов

  🎒 РЮКЗАК (клавиша I или кнопка «Рюкзак»):
  Хотбар ПУСТ по умолчанию — как в майнкрафте.
  Открой рюкзак → там видно ресурсы и что можно
  скрафтить/поставить. Кликни предмет, затем кликни
  ячейку хотбара внизу — предмет ляжет в неё. Клик по
  ячейке без выбранного предмета — очистить её.
  Раскладка хотбара сохраняется между попытками.

  ХОТБАР (1-9): выбери ячейку, жми Q — использовать
  назначенный в неё предмет.
    🍖/🍓 — съесть
    🕯️ Факел = 1🪵          🔥 Костёр = 2🪵 + 1🪨
    🧱 Стена = 2🪨          🛠️ Верстак = 4🪵
    🌱 Грядка = 2🪵 (нужен верстак рядом)
    🌰 Посадить = 1🍓 (на пустую грядку)

  🛠️ ВЕРСТАК: поставь его — рядом с ним открываются
  «продвинутые» рецепты (грядка).

  СТРОЙКА: 🧱 стена непроходима и блокирует мобов;
  ломается ударами (Space/E).

  ФЕРМА: поставь грядку → «Посадить» (1🍓) → она
  растёт ~3 стадии → собери урожай Space/E (+3🍓).

  МОБЫ 👾: ночью идут к тебе и бьют. Бей их Space/E
  (падает 🍖 мясо). Днём мобы сгорают.

ПОКАЗАТЕЛИ
──────────────────────────────────────────────
  ❤️ Здоровье  🍖 Голод  🔥 Тепло

🌐 ОНЛАЙН-КООП (вдвоём по сети, P2P)
──────────────────────────────────────────────
  «Создать комнату» — ты становишься хостом, появляется
  КОД. Отправь код другу.
  Друг вводит КОД в поле и жмёт «Войти».
  Общая карта, общий склад и показатели; у каждого свой
  игрок и свой факел. Ночью грейтесь ОБА у костра —
  если кто-то один замёрзнет, тепло падает у всех.
  ВАЖНО: онлайн работает только по ссылке http(s)
  (например, GitHub Pages), НЕ через file://. Нужен
  интернет у обоих. Связь P2P (PeerJS) — при «строгом»
  NAT может не соединиться; тогда попробуйте ещё раз.

ПРАВИЛА
──────────────────────────────────────────────
  Днём исследуй карту и собирай ресурсы. Голод падает
  постоянно — ешь ягоды, иначе начнёт падать здоровье.
  НОЧЬЮ наступает полная темнота. Если ты НЕ рядом с
  костром (радиус ~3 клетки) и без факела — падает Тепло,
  затем Здоровье. Разведи костёр или зажги факел, чтобы
  пережить ночь. Костёр гаснет со временем — встань на
  него и подкинь дров («Костёр» с 🪵).
  Цель — прожить как можно больше дней. Рекорд сохраняется.
