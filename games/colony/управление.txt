╚══════════════════════════════════════════╝

Текстовый менеджер ресурсов в стиле Reigns.

УПРАВЛЕНИЕ
──────────────────────────────────────────────
  Клик по левому варианту .... принять левое решение
  Клик по правому варианту ... принять правое решение
  ← / → ...................... левое / правое решение
  Наведение на вариант ....... показать направление
                               эффекта (▲ рост / ▼ падение)
  🔄 Заново / Enter .......... новая игра

РЕСУРСЫ (держи в среднем диапазоне!)
──────────────────────────────────────────────
  🍞 Еда       💰 Деньги      🛡️ Защита      ⚡ Энергия
  Все начинают с 50 из 100.

ПРАВИЛА
──────────────────────────────────────────────
  Каждый день — событие и ДВА решения. Любое решение
  двигает несколько ресурсов вверх или вниз.
  ОПАСНЫ ОБА КРАЯ: если ЛЮБОЙ ресурс упадёт до 0
  ИЛИ поднимется до 100 — колонии конец (свой финал
  для каждого случая).
  Точные числа скрыты — при наведении видно только
  НАПРАВЛЕНИЕ эффекта. Балансируй!
  Цель — прожить как можно больше дней.
  Рекорд сохраняется в браузере.

ПОЛНЫЙ ЭКРАН
──────────────────────────────────────────────
  ⛶ Во весь экран ........ кнопка рядом с «Меню»
  F ...................... то же с клавиатуры
  Esc .................... выйти обратно

  В этом режиме видно ТОЛЬКО игру: заголовок,
  навигация и справочник скрываются, а поле
  растягивается почти на весь экран (пропорции
  сохраняются, картинка не искажается).
  На компьютере экранные кнопки-дубли прячутся —
  всё управление на клавиатуре; на телефоне они
  остаются.
