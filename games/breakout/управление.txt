КЛАВИАТУРА / МЫШЬ
──────────────────────────────────────────────
  Движение мыши ........... двигать платформу
  ← / A / Ф ............... платформа влево
  → / D / В ............... платформа вправо
  Пробел (Space) .......... запустить мяч / огонь лазера
  P / Esc / З ............. пауза / продолжить
  Enter ................... заново (после проигрыша)

СЕНСОР (телефон / планшет)
──────────────────────────────────────────────
  Веди пальцем ............ двигать платформу
  Тап .................... запуск мяча / огонь лазера
  Тап после проигрыша ..... начать заново

КНОПКИ / НАСТРОЙКИ НА ЭКРАНЕ
──────────────────────────────────────────────
  Список сложности ........ Легко / Средне / Сложно
                            (скорость мяча)
  ⏸ Пауза / ▶ Продолжить .. поставить/снять паузу
  🔄 Заново ............... начать сначала

БОНУСЫ (падают из блоков — лови платформой)
──────────────────────────────────────────────
  🟠 W .... шире платформа (на время)
  🟣 3x ... разделить на 3 мяча
  🔵 S .... замедлить мяч (на время)
  ⚡ ...... лазер: платформа стреляет (Пробел/тап)
  ❤️ ...... +1 жизнь

ЦЕЛЬ И ОЧКИ
──────────────────────────────────────────────
  Отбивай мяч платформой и разбивай все блоки.
  Крепкие блоки требуют нескольких попаданий (цвет = прочность:
  🟢1 → 🟡2 → 🟠3 → 🔴4). Попадание +10, разрушение +20.
  Разбил все блоки — следующий уровень (мяч быстрее, блоков больше).
  Мяч упал мимо платформы — минус жизнь. Жизней 3.
  Угол отскока зависит от точки удара по платформе.
  Рекорд сохраняется в браузере.
