КЛАВИАТУРА
──────────────────────────────────────────────
  ← / A / Ф ............... двигать влево
  → / D / В ............... двигать вправо
  ↑ / X / Ч ............... поворот по часовой
  Z / Я ................... поворот против часовой
  ↓ / S / Ы ............... ускорить падение (soft drop)
  Пробел (Space) .......... мгновенный сброс (hard drop)
  C / С ................... отложить фигуру (HOLD)
  P / Esc / З ............. пауза / продолжить
  Enter ................... заново (после проигрыша)

СЕНСОР (телефон / планшет)
──────────────────────────────────────────────
  Веди пальцем вбок ....... двигать фигуру
  Короткий тап ............ поворот
  Свайп вниз .............. мгновенный сброс
  Тап после проигрыша ..... начать заново

КНОПКИ НА ЭКРАНЕ
──────────────────────────────────────────────
  ⏸ Пауза / ▶ Продолжить .. поставить/снять паузу
  🔄 Заново ............... начать сначала

ПОДСКАЗКИ НА ПОЛЕ
──────────────────────────────────────────────
  СЛЕДУЮЩИЕ ..... три будущие фигуры справа
  ОТЛОЖЕНО (C) .. отложенная фигура (обмен по кнопке C)
  Призрак ....... контур снизу показывает, куда упадёт

ЦЕЛЬ И ОЧКИ
──────────────────────────────────────────────
  Складывай тетромино в сплошные горизонтальные линии —
  они исчезают и приносят очки:
     1 линия — 100,  2 — 300,  3 — 500,  4 (тетрис) — 800
  (× текущий уровень). Каждые 10 линий — новый уровень
  и более быстрое падение. Soft drop +1, hard drop +2 за клетку.
  Игра кончается, когда фигурам некуда падать.
  Рекорд сохраняется в браузере.
