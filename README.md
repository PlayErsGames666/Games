# 🎮 Games

Коллекция простых браузерных игр на чистом HTML/CSS/JavaScript. Всё работает офлайн — просто открой файл в браузере, ничего устанавливать не нужно.

## Как играть

Открой **`index.html`** — это общее меню-игротека: наведи курсор на плитку, чтобы увидеть живое превью игры, и кликни, чтобы играть. У каждой игры рядом с полем есть панель-справочник с управлением.

## Список игр

| Игра | Файл | Управление |
|------|------|-----------|
| 💣 Сапёр | `saper.html` | мышь (ЛКМ / ПКМ) |
| ⭕ Крестики-нолики | `tictactoe.html` | мышь · есть режим против ИИ |
| 🔢 Пятнашки | `pyatnashki.html` | стрелки / мышь |
| 🍪 Печенька-кликер | `clicker.html` | мышь · автосохранение |
| 🏓 Pong | `pong.html` | ↑ ↓ / W S / мышь · Пробел — пауза |
| 🐍 Змейка | `snake.html` | стрелки / WASD · Пробел — пауза |
| 🐤 Flappy | `flappy.html` | Пробел / ↑ / клик · P, Esc — пауза |

Рядом с каждой игрой лежит текстовый гайд по управлению: `<игра>-управление.txt`.

## Технологии

Без зависимостей и сборки — только браузер. Игры на `<canvas>` (Pong, Змейка, Flappy) идут на 60 FPS через `requestAnimationFrame`, рекорды сохраняются в `localStorage`.
