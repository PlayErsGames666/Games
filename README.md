# 🎮 Games

Коллекция простых браузерных игр на чистом HTML/CSS/JavaScript. Всё работает офлайн — просто открой файл в браузере, ничего устанавливать не нужно.

## Как играть

Открой **`index.html`** в корне — это общий шлюз-игротека: наведи курсор на плитку, чтобы увидеть живое превью игры, и кликни, чтобы играть. У каждой игры рядом с полем есть панель-справочник с управлением.

Каждая игра также полностью самодостаточна — можно открыть её напрямую, например `games/snake/index.html`.

## Структура

Проект разложен по принципу микросервисов: в корне — шлюз и документация, а каждая игра живёт в собственной изолированной папке под `games/` со своим `index.html` и гайдом по управлению.

```
.
├── index.html            # шлюз-меню со ссылками и живым превью всех игр
├── README.md
└── games/
    ├── saper/            # 💣 Сапёр
    │   ├── index.html
    │   └── управление.txt
    ├── tictactoe/        # ⭕ Крестики-нолики
    ├── pyatnashki/       # 🔢 Пятнашки
    ├── clicker/          # 🍪 Печенька-кликер
    ├── pong/             # 🏓 Pong
    ├── snake/            # 🐍 Змейка
    ├── flappy/           # 🐤 Flappy
    ├── invaders/         # 👾 Space Invaders
    ├── tetris/           # 🧱 Тетрис
    ├── breakout/         # 🕹️ Арканоид
    ├── pacman/           # 🟡 Лабиринт (Пакман-лайт)
    ├── dino/             # 🦕 Динозаврик (бегущий раннер)
    ├── timberman/        # 🪓 Timberman (руби дерево)
    ├── stack/            # 🏗️ Stack (собери башню)
    ├── copter/           # 🚀 Ракета в пещере (Flappy Copter)
    ├── blackjack/        # 🃏 Блекджек (21)
    ├── durak/            # 🎴 Дурак (подкидной / переводной)
    ├── colony/           # 🛰️ Колония (симулятор выживания, Reigns-style)
    ├── survival/         # 🌲 Выживание на тайловой карте (Don't Starve Lite)
    └── raft/             # 🛟 Микро-Raft (выживание на плоту)
```

Каждая папка `games/<игра>/` содержит:
- `index.html` — сама игра, самодостаточный модуль без зависимостей;
- `управление.txt` — текстовый справочник по клавишам.

## Полный экран

В каждой игре есть кнопка **⛶ Во весь экран** и клавиша **F**
(в «Выживании» ради этого быстрая еда переехала с F на **G**).

Это **изоляция игрового экрана**: скрываются заголовок, навигация, справочник
и подсказки — остаётся только сама игра на тёмном фоне, растянутая почти во весь
экран с сохранением пропорций (без искажений). Игровые кнопки, без которых
не сыграть («Бито/Взять» в Дураке, крафт в Raft), остаются на месте.
На компьютере экранный D-pad скрывается — управление на клавиатуре;
на телефоне он остаётся.

В «Выживании» показатели, ресурсы и хотбар нарисованы **внутри игрового экрана**,
поэтому в полноэкранном режиме ничего не теряется.

## Технологии

Без зависимостей и сборки — только браузер. Игры на `<canvas>` (Pong, Змейка, Flappy) идут на 60 FPS через `requestAnimationFrame`, рекорды сохраняются в `localStorage`.
