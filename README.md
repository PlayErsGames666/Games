# 🎮 Games

Коллекция простых браузерных игр на чистом HTML/CSS/JavaScript. Всё работает офлайн — просто открой файл в браузере, ничего устанавливать не нужно.

## Как играть

Открой **`index.html`** в корне — это общий шлюз-игротека: наведи курсор на плитку, чтобы увидеть живое превью игры, и кликни, чтобы играть. У каждой игры рядом с полем есть панель-справочник с управлением.

Каждая игра также полностью самодостаточна — можно открыть её напрямую, например `games/snake/index.html`.

## Структура

Каждая игра — отдельный самодостаточный модуль в своей папке под `games/`: разметка, стили и логика лежат по разным файлам, общее вынесено в `shared/`. В корне — шлюз-меню и документация.

## Как устроено

Каждая игра — три файла: `index.html` (разметка), `style.css` (её стили),
`game.js` (её логика). Плюс `управление.txt` — справочник по клавишам.
Одинаковых копий больше нет: то, что раньше повторялось в каждой игре,
лежит в `shared/`.

| Файл | Что там |
|------|---------|
| `shared/base.css` | каркас страницы: раскладка `.stage`/`.game-col`, справочник, весь полноэкранный режим |
| `shared/fullscreen.js` | кнопка ⛶ и клавиша F. Раньше этот скрипт лежал копией в 24 играх и успел разойтись — где-то чинили одно, где-то другое |
| `shared/net.js` | комнаты, коды, соединение, слоты игроков |
| `shared/net.css` | панель комнаты — одинаковая во всех играх |

Порядок подключения в игре: сначала `shared/base.css`, потом `style.css`.
Игра переопределяет у себя всё, что хочет сделать по-своему (свой цвет
кнопки полного экрана, свой фон), и её правило побеждает по порядку каскада.

Исключение сделано для `:fullscreen canvas`: пиксельным играм нужен
`image-rendering: pixelated`, а тем, кто перерисовывается в реальном
разрешении экрана (Астероид, Конвейер, Рубеж, Тихий квартал), — наоборот,
сглаживание. Общее правило подтекало бы им и мылило картинку, поэтому
эта строчка осталась у каждой игры своя.

Сборки по-прежнему нет: обычные `<link>` и `<script>`, никаких модулей —
так игра открывается двойным щелчком по файлу, без сервера.

**Версия в ссылках.** Все локальные css и js подключаются с `?v=ГГГГММДД`.
GitHub Pages отдаёт файлы с длинным кешем, и без этого браузер после
правки общего `shared/fullscreen.js` продолжает крутить старую копию —
человек видит «ничего не изменилось». **Поменял что-то в `shared/` —
подними версию во всех `index.html`.**

## Полный экран

В каждой игре есть кнопка **⛶ Во весь экран** и клавиша **F**
(в «Выживании» ради этого быстрая еда переехала с F на **G**).

Это **изоляция игрового экрана**: скрываются заголовок, навигация, справочник
и подсказки — остаётся только сама игра на тёмном фоне, растянутая почти во весь
экран с сохранением пропорций (без искажений). Игровые кнопки, без которых
не сыграть («Бито/Взять» в Дураке, крафт в Raft), остаются на месте.
На компьютере экранный D-pad скрывается — управление на клавиатуре;
на телефоне он остаётся.

В «Выживании» показатели, ресурсы и хотбар нарисованы **внутри игрового экрана**,
поэтому в полноэкранном режиме ничего не теряется.

## Игра по сети

Восемь игр помечены 🌐 — в них можно играть вместе по коду комнаты:
Крестики-нолики, Pong, Дурак, Блекджек, Выживание, Микро-Raft,
Дрейфующий астероид и Тихий квартал.

Один жмёт «🌐 Создать комнату» и получает код из четырёх знаков,
остальные вводят его и жмут «Войти». Код без похожих букв (ни `0/O`,
ни `1/I`) — его можно продиктовать голосом.

Модель везде одна: **хозяин комнаты считает, остальные шлют ввод**.
Гость ничего не решает сам — он просит, получает готовое состояние
и рисует его. Сверять детерминированную симуляцию на разных браузерах
дороже, чем просто прислать состояние 15 раз в секунду.

Что из этого следует:

- выйдет хозяин — партия заканчивается;
- «Заново» онлайн начинает хозяин, у гостя кнопка шлёт ему просьбу;
- подделать ход нельзя: правила проверяет хозяин;
- чужие карты и закрытая карта дилера **не отправляются вообще** —
  их нет в пакете, а не «спрятаны» стилем.

Технически это WebRTC через PeerJS: браузеры соединяются напрямую,
сервер нужен только чтобы найти друг друга. Для строгих сетей
(мобильный интернет, рабочий Wi-Fi) прописан ретранслятор TURN —
медленнее, но соединение есть. Весь сетевой слой лежит в
`shared/net.js`, одинаковый для всех игр.

## Технологии

Без зависимостей и сборки — только браузер. Игры на `<canvas>` (Pong, Змейка, Flappy) идут на 60 FPS через `requestAnimationFrame`, рекорды сохраняются в `localStorage`.
